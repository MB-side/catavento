# Reference mockups

These five files are exported from the design canvas. They are **visual references only**: never import them, copy their markup into the app, or treat their sample numbers as data. Build the real components from `docs/06-design-spec.md`.

They use a design-canvas HTML format (`.dc.html`): open them in a browser to view the layout (some styling depends on the canvas runtime, so treat what you see as approximate) or read the inline styles for exact colours, sizes and spacing.

| File | Screen | Iteration 1 differences |
|---|---|---|
| `Main.dc.html` | My Sites (phone, 390 px wide) | `docs/06` §7 |
| `SitePage.dc.html` | Site page, Long Reef NE (phone) | `docs/06` §7 |
| `SitePageDesktop.dc.html` | Site page, Long Reef NE (desktop, fluid) | `docs/06` §7 |
| `ClubPage.dc.html` | Club page, Sydney Paragliding & Hang Gliding Club (desktop, fluid) | `docs/06` §7 |
| `SharePreview.dc.html` | Share image, 1200 × 630 | `docs/06` §7 |

Values marked as sample data, weather readings and anything in square brackets are illustrative. The HouseThermal wordmark and logo mark in the headers are the reference for `docs/06` §9. The desktop screens also show the country switcher and country-first breadcrumbs (`docs/01` §4.1).
