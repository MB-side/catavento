| D6 | 2026-10-09 | **"New to flying"** replaces "Learn to fly" and covers both tandem flights and learning; schools live here | People wanting a one-off tandem and people wanting to learn arrive with the same "I'm new" mindset |
| D7 | 2026-10-09 | Iteration 1 is a static, non-commercial consultation prototype on GitHub Pages, built with Next.js static export so the same app moves to Vercel + Supabase in Iteration 2 | Free, simple hosting for feedback; no rework later |

| D11 | 2026-10-09 | No live wind values in Iteration 1; stations are links | Static hosting cannot fetch server-side; permissions not yet requested |
| D12 | 2026-10-09 | Data precedence: manual overrides > ingest > seed | Human corrections must always win |
| D13 | 2026-10-09 | Light theme only in Iteration 1 | Scope control |
| D14 | 2026-10-08 | Revenue features stay off until usage thresholds are met (`docs/08` §3) | Protect neutrality and trust while building the habit |

| D16 | 2026-10-09 | Always one word, always paired with the descriptor "Paragliding and hang gliding, all in one place"; explain the name once on home and About | The two-word phrase collides with home-heating search results; newcomers need the plain descriptor |
